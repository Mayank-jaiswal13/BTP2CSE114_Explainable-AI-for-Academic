## 💡 Customization Options

### Easy to Change
1. **Colors**: Edit CSS variables in `style.css`
2. **Text**: Update HTML content in templates
3. **Users**: Modify `USERS` dict in `app.py`
4. **Features**: Add form fields to form and prediction function
5. **Port**: Change in `app.py` run() call

### Configuration Examples

#### Change Color Theme
```css
/* In static/css/style.css */
:root {
    --primary-color: #your-color;
    --secondary-color: #your-other-color;
}
```

#### Add New User
```python
# In app.py
USERS = {
    'admin': 'admin123',
    'your_user': 'your_password'  # Add here
}
```

#### Change Port
```python
# In app.py
if __name__ == '__main__':
    app.run(debug=True, port=5001)  # Change port
```
